DigiBuy — как добавить на экран «Домой» iPhone

1. Выложите папку digibuy на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages).
   Файлы: index.html и manifest.json лежат рядом.
2. Откройте ссылку в Safari на iPhone.
3. Нажмите «Поделиться» (квадрат со стрелкой) → «На экран "Домой"» → «Добавить».
4. Запускайте игру с иконки: она откроется без адресной строки.

Прогресс хранится в localStorage этого устройства. Он сбрасывается, если очистить данные сайта или удалить иконку.
Код П-Банка по умолчанию: 1234.
Игра работает офлайн после первого открытия страницы.
